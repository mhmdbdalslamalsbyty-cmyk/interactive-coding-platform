# مسار الكود — منصة عربية تفاعلية لتعلّم البرمجة

«مسار الكود» منصة ثابتة تعمل مباشرة في المتصفح لتعلم **Python** و**HTML/CSS** و**C++**. تضم المنصة 18 درساً قصيراً، مثالاً قابلاً للتحرير في كل درس، اختبار فهم مع تصحيح تلقائي، ومؤشر تقدم محفوظ محلياً في المتصفح.

## ما الذي ستجده هنا؟

| المسار | المحتوى | أسلوب التجربة |
|---|---|---|
| Python | المتغيرات، هياكل البيانات، الدوال، الكائنات، الملفات، مشروع محلل النص | Brython داخل المتصفح |
| HTML وCSS | HTML الدلالي، النماذج، الصندوق، Flexbox، Grid، التصميم المتجاوب | معاينة `iframe` مباشرة |
| C++ | الأساسيات، `vector`، المؤشرات، الذاكرة، الكائنات، الملفات | أمثلة تدريبية قابلة للنسخ |

تتوفر الكتب العربية القابلة للتحميل داخل مجلد [`docs/downloads`](docs/downloads):

| الكتاب | رابط الملف |
|---|---|
| تعلم Python من الصفر إلى الاحتراف | [`learn-python-ar.pdf`](docs/downloads/learn-python-ar.pdf) |
| تعلم HTML وCSS من الأساس إلى الاحتراف | [`learn-html-css-ar.pdf`](docs/downloads/learn-html-css-ar.pdf) |
| تعلم C++ من الصفر إلى الاحتراف | [`learn-cpp-ar.pdf`](docs/downloads/learn-cpp-ar.pdf) |

## تشغيل الموقع محلياً

لا تحتاج إلى تثبيت مكتبة خاصة. افتح ملف [`docs/index.html`](docs/index.html) في متصفح حديث، أو شغّل خادماً ثابتاً داخل مجلد `docs`. تتبع الصفحة البنية التالية التي تناسب GitHub Pages:

```text
docs/
├── index.html
├── styles.css
├── script.js
├── lessons/
│   └── catalog.js
└── downloads/
    ├── learn-python-ar.pdf
    ├── learn-html-css-ar.pdf
    └── learn-cpp-ar.pdf
```

## ملاحظات مهمة

تعمل تجارب Python في المتصفح عبر Brython؛ لذلك يكفي اتصال إنترنت في المرة الأولى لتحميل المكتبة من الشبكة. أما C++ فلا يُنفَّذ داخل المتصفح في هذه النسخة، لأن تشغيل كود C++ محلياً بشكل آمن يحتاج مترجماً مستقلاً مثل `g++`. يحتفظ الموقع بالتقدم ووضع العرض على جهاز المستخدم فقط ولا يرسل أي بيانات أو يطلب حساباً.
